# Troubleshooting Guide

## Common Issues

### "FFmpeg not found"

The startup check (`backend/startup_check.py`) validates FFmpeg availability. If missing:

1. Download `ffmpeg.exe` and `ffprobe.exe` from [ffmpeg.org](https://ffmpeg.org/download.html) or [Gyan.dev](https://www.gyan.dev/ffmpeg/builds/)
2. Place them in the project's `ffmpeg/` directory
3. Restart the backend

### Backend won't start

Check the startup validation:

```bash
python backend/startup_check.py
```

This runs all startup checks independently and reports:
- FFmpeg availability
- Queue file integrity
- Directory write permissions

### Portable ZIP won't extract

Ensure you have enough disk space. The ZIP contains the companion EXE plus FFmpeg binaries.

### "PyInstaller build failed"

Ensure PyInstaller is installed:

```bash
pip install pyinstaller
```

Then verify the spec file syntax:

```bash
pyinstaller --debug MediaForge.spec
```

### Version mismatch errors

Run the version verification script:

```bash
python scripts/verify_versions.py
```

This checks that `VERSION` matches all source files. Update all mismatched references.

## Logs

- Companion logs: `companion/logs/companion.log` (rotated at 5 MB, 3 backups)
- Backend logs: Printed to console (configure logging in `app.py`)
- Test logs: `build_test.log` (generated by build.bat)
