# Release Checklist

Use this checklist for every MediaForge release. Tick each item after verification.

---

## Pre-Release

- [ ] `git checkout main && git pull`
- [ ] `git status` — working tree is clean
- [ ] Version number updated in `companion/updater.py` (`COMPANION_VERSION`)
- [ ] `CHANGELOG.md` updated with all changes for this release
- [ ] Changelog reviewed for accuracy and completeness

## Build Verification

- [ ] `python -m py_compile companion/*.py` — all compile without errors
- [ ] `python -m py_compile backend/app.py` — backend compiles without errors
- [ ] Run companion unit tests: `python -m unittest discover -s companion -p "test_*.py" -v` — **all pass**
- [ ] Run backend unit tests: `python -m unittest discover -s backend -p "test_*.py" -v` — **all pass**
- [ ] `cd backend && python app.py` — backend starts without errors
- [ ] FFmpeg binaries present in `ffmpeg/` directory

## Manual Testing

- [ ] Backend starts and serves at `http://127.0.0.1:5000`
- [ ] MP3 download works
- [ ] 1080p download works
- [ ] 4K/8K download works (with fallback)
- [ ] Playlist download works
- [ ] Download history loads and displays correctly
- [ ] Clear history works
- [ ] Companion auto updater checks for updates
- [ ] Companion installer launches (if applicable)
- [ ] Companion system tray icon functions
- [ ] Extension popup connects to backend
- [ ] Extension download panel shows queue
- [ ] Settings save and load correctly
- [ ] Theme change applies correctly

## Release

- [ ] `git tag v<version>` — annotated tag created (e.g., `v1.2.0`)
- [ ] `git push origin main --tags` — tags pushed to remote
- [ ] GitHub Release created at `https://github.com/kronpatel/MediaForge/releases`
- [ ] Release title matches version (e.g., `v1.2.0`)
- [ ] Release notes written (can use CHANGELOG.md content)
- [ ] Assets uploaded:
  - [ ] `MediaForge-Setup.exe` (if applicable)
  - [ ] Source code archive (auto-generated by GitHub)

## Post-Release

- [ ] Companion auto updater detects new version (test on a clean install)
- [ ] Installer tested on a fresh machine (if applicable)
- [ ] Backend tested on a fresh Python environment (`pip install -r backend/requirements.txt`)
- [ ] Release announcement drafted (if applicable)
