# Security Policy

We take the security of MediaForge seriously. Thank you for helping us keep this project secure.

---

## Supported Versions

Only the latest release version of MediaForge is currently supported with security updates. We encourage all users to run the latest code.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

---

## Supported Platforms

MediaForge is supported on the following environment profiles:

*   **Operating Systems**: Windows 10 & Windows 11 (necessary for the companion application tray interface, auto updater, installer, and scheduled runs).
*   **Browsers**: Google Chrome, Microsoft Edge, Brave, Opera, and other Chromium-based browsers (for browser extension layout features).
*   **Python**: Python 3.10 through 3.13 (CI checked).

---

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

If you discover a security vulnerability in this project, please report it confidentially:

1.  Send an email to the security contact: **keronpatel5656@gmail.com**.
2.  Include a detailed description of the vulnerability, steps to reproduce, and a proof-of-concept if available.

---

## Disclosure Policy & SLA

*   **Expected Response Timeline**: We will acknowledge and respond to your report within **48 hours**.
*   **Resolution and Patching**: We will work with you to analyze, reproduce, and patch the vulnerability. Once a fix is verified and pushed to the repository, we will publish a new release and credit you for the discovery.
